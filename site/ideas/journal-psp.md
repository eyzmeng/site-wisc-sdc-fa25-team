## Pitch

I like to write diaries!

They're usually words, but sometimes I like to add pictures.

![An entry from not so long ago](https://www.rapidcow.org/~ethan/diary.jpg)

I don't usually make entries like these, but you get the point...
pictures are essential to diaries! ;)

Problem is, there are not many good diary apps out there: they are either
too distracting, or lock essential features such as multi-media support
and exporting data behind a paywall (or don't get a lot of love like my
favorite journaling app [Perspective](https://blinky.co/press-kit-perspective/).... :,<)
That's why I started the [Perspective Project](https://www.rapidcow.org/project/perspective/)
(named after my aforementioned favorite app),
which aims to achieve the following goals:

*   A standardized, content-agonistic **model** of entries
    with detailed specification of an on-the-wire serialization
    and deserialization format (initially JSON, but later also
    key-value headers + payload)
    
*   The on-disk data, backed by a schema, thus equipped with
    structure and, in turn, **validation** logic, which would
    help catch obvious inconsistencies arising from human errors.

*   The interface, the display, the **presentation** of data
    in a clean, tidy fashion (which, to me, is another layer of
    reassurance since I'm a very visual person :)

The result of the project was... messy, to put it lightly.
I tried too hard extending an existing model of one file per entry
by fitting in multi-media content.  So Python library ended up as
the messiest and most unclean code you will ever see, in a way that
I don't really see how to fix....  But the intent of my project remains
the same: an implementation-independent, interoperability and
representation first approach to diary archival (and messages,
threads, forums, discussions in general).

To say it is just about diary is a bit of an understatement...
this is quite an ambitious project that rightfully falls under
"help me out if you want but i'm fine if you don't lol". (￣▽￣||)
